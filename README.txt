Публичный сайт: Плейлист by @ween7777

Это обычный статический сайт (index.html + assets). Серверу ничего считать не нужно.

Как выложить, чтобы мог зайти любой человек (выбери один вариант):
1. Netlify Drop: открой app.netlify.com/drop, перетащи сюда всю папку. Получишь ссылку.
2. GitHub Pages: создай репозиторий, загрузи файлы, в Settings > Pages включи публикацию ветки main.
3. Cloudflare Pages или Vercel: создай проект и загрузи эту папку.

Музыка и обложки: в этой версии звука нет, а вместо обложек стоят градиенты. Страница работает в режиме «оформление и текст».
Чтобы добавить звук, положи свой аудиофайл в assets/ и впиши путь в поле src у нужной песни
в массиве TRACKS внутри index.html, например src:"assets/moy-trek.mp3".
Выкладывай в открытый доступ только то, что тебе можно публиковать.

Тексты песен посетители вставляют сами кнопкой «Вставить текст». Они хранятся в браузере
каждого человека и никуда не отправляются.

Чтобы добавить обложку: создай папку assets, положи туда картинку и впиши путь в поле cover,
например cover:"assets/cover.jpg".

Чтобы вшить текст песни в сайт: в index.html у нужной песни в массиве TRACKS есть поле lyrics:``.
Вставь текст между обратными кавычками, по одной строке на строчку. Выкладывай только тексты,
которые тебе можно публиковать.
